Privacy Policy

Application: Dossier
Effective date: November 9, 2026

This policy describes the intended privacy practices for Dossier, a locally run personal job-application assistant. It must be read together with the actual application behavior and the permissions shown by Google during connection.

Google account access

If the user chooses to connect a Google account, Dossier requests access to the specific Gmail and Google Calendar data described on Google's consent screen. The intended purpose is to support job-application workflows, such as finding application-related messages, preparing replies or application drafts, and checking calendar availability.

Dossier should access Google account data only after the user initiates the connection and grants permission. The user can decline or revoke access through their Google Account security settings.

How information is used

Information made available through the connected Google services is intended to be used to provide the features the user requests within Dossier. The application may also process information the user enters, such as job details and application notes, to provide those features.

Email sending and user control

Preparing an email draft is not the same as sending it. The user should be shown the message and must take an explicit send action before an email is sent. Users should review recipients, content, and attachments before sending.

Storage, retention, and service providers

Dossier is run locally by its user. The exact storage location, retention period, backup behavior, and any third-party processing depend on the installed version and its configuration. The operator must document these details accurately before distributing Dossier or requesting broad public access to Google user data. Do not assume that local operation means that no information is transmitted to other services.

Sharing and sale

The application is not intended to sell users' personal information. Any sharing with service providers or other parties must be limited to what is necessary for the features the user has chosen and must be disclosed by the application operator.

Security

Users should keep their device, application configuration, OAuth credentials, and access tokens secure. Never publish client secrets, tokens, or private application data in a public repository. No method of storage or transmission can be guaranteed to be completely secure.

Children

Dossier is intended for adults managing their own job-search activities and is not designed for children.

Changes and contact

This policy may be updated when the application's features or data practices change. For privacy questions, contact the Dossier operator at the contact address provided in the application's Google OAuth consent screen.

Important setup note: This is an initial policy draft. Before using it for public OAuth verification, the operator must confirm the app's real data storage, retention, and any AI or other third-party processing, then update this page so it precisely matches the code and actual practices.
