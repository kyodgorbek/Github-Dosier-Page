Dossier

Personal Job Application Assistant

Dossier is a locally run application designed to help an individual organize job applications and related communications. When configured by the user, it can connect to Google services to support job-search workflows such as reviewing relevant email conversations, preparing application-related drafts, and checking calendar availability.

Dossier does not send an email merely because a draft is prepared. The user should review and explicitly approve any message before it is sent.

Availability: This site provides information about the Dossier application. It is not a public account portal or a hosted version of the application.
